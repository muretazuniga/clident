# CLIDENT

Aplicación de gestión para clínicas dentales. Centraliza pacientes, profesionales, citas y atenciones clínicas en una interfaz simple y adaptable a dispositivos móviles.

Proyecto de la asignatura Portafolio de Título (PTY4479), Duoc UC.
Integrantes: Belén Bustos y Matías Ureta.

## Tecnologías

- Angular 20
- Ionic 8
- Capacitor 7 (plugins de cámara, teclado, status bar y haptics)
- Ionic Storage (persistencia local de datos)
- TypeScript
- GitHub (control de versiones)

## Funcionalidades

- Inicio de sesión, sesión persistente y rutas protegidas (AuthGuard).
- Gestión de pacientes (crear, consultar, editar, eliminar).
- Gestión de profesionales y sus especialidades.
- Agenda de citas asociando paciente, profesional, fecha, hora y motivo.
- Registro de atenciones clínicas (diagnóstico, tratamiento, observaciones).
- Historial de atenciones por paciente.
- Foto de perfil desde la galería del dispositivo.

## Cómo ejecutar

```bash
npm install
ionic serve
```
